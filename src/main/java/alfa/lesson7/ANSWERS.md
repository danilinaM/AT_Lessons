1. Почему heroesCreated должно быть статическим? 
Потому что оно принадлежит классу целиком, а не каждому объекту класса Hero
2. Почему name, health и level не должны быть статическими?
Потому что эти поля свои для каждого объекта класса Hero
3. Почему printHeroesCreated() можно вызвать без создания объекта?
Потому что это статический метод
4. Можно ли из статического метода напрямую обратиться к нестатическому полю name? Почему?
Нет, потому что без объекта статический метод не знает, к какому name обращаться
5. Почему проект перестанет компилироваться если пометить класс Hero модификатором final?
Если пометить класс Hero модификатором final, то от него нельзя будет наследоваться 
6. почему переменные имеют тип Hero, но при этом вызываются версии метода attack() из конкретных наследников?
Потому что тип переменной Hero, но реальные объекты внутри тиаов-наследников. При вызове переопределенного метода вызываются версия 
метода по реальному типу объекта, а не по типу переменной
7. почему переменная knight имеет модификатор final но ее поля могут быть изменены? 
Потому что final запрещает изменять саму ссылку на объект, но сам объект остается изменяемым и его поля можно менять через методы
